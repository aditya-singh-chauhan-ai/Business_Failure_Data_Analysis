# 📊 Business Failure Analysis Dashboard

An interactive **Excel dashboard** for analyzing business failure data across different regions, years, and quarters. The project uses **Pivot Tables, Pivot Charts, filters, and slicers** to transform raw data into meaningful visual insights.

### 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables & Pivot Charts
* Slicers & Filters
* Data Analysis & Visualization

### 📌 Key Analysis

* Regional business failure comparison
* Year-wise failure trends
* Quarterly analysis
* Regional distribution of failure units
* Interactive dashboard for exploring the data

### 🎯 Objective

To analyze business failure patterns and present important trends and regional insights through an interactive Excel dashboard.
